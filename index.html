REMOVAL WORKFLOW

Discover → Request → Verify

1

Discover

Run local checks and source-specific searches. Save only the minimum evidence needed.

2

Request

Open the official removal route and generate a ready-to-send request without handing credentials to us.

3

Verify

Re-run the search later and mark each source removed, pending, refused or reappeared.

PRIVACY MODEL

Designed to be self-hosted by anyone.

No backend

GitHub Pages serves static HTML, CSS and JavaScript. No application server is required.

No secrets

No API keys, tokens or paid provider credentials are bundled into the site.

Open data

Source directories and optional datasets can live in the repository and be version-controlled.

User controlled

Search values stay in the browser unless the user deliberately opens an external search or removal page.
